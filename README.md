# 🌡️ IoT Temperature Dashboard

A real-time IoT temperature monitoring dashboard built using **Node.js, MQTT, WebSocket, SQL Server, HTML, CSS, JavaScript and Chart.js**.

This project demonstrates how temperature data can be generated by an IoT device, transmitted using MQTT, processed by a Node.js server, stored in SQL Server, and displayed on a real-time web dashboard.

---

## 📌 Project Overview

The IoT Temperature Dashboard is a real-time temperature monitoring system.

A simulated temperature device generates a new temperature reading every 2 seconds and publishes it to an MQTT topic.

The Node.js server receives the temperature through MQTT, stores it in SQL Server, calculates dashboard KPIs, and sends real-time updates to the frontend using WebSocket.

The frontend displays:

* Current Temperature
* Highest Temperature
* Lowest Temperature
* Temperature Graph
* Temperature History
* Pagination
